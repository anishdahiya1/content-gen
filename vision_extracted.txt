Vision
CreatorPilot AI is an AI-powered content operating system that turns one long-form video into a full set of platform-ready, short-form assets — automatically.
Upload a video once. Get back Shorts, Reels, clips, captions, titles, hashtags, and basic analytics, ready to publish.
Why Build This as a Student Project
Real product, real constraints: shows you can scope, build, and ship something end-to-end, not just follow a tutorial.
Built-in content engine: every feature you build is also a LinkedIn post — &quot;day 4 of building an AI tool that repurposes video&quot; type content.
Zero cost: every tool in this stack has a generous free tier, so this is fundable on a student budget.
Dual purpose: it&apos;s both the project you ship AND the subject you post about — the build documents itself.
Problem Statement
Creators spend most of their time on repetitive, mechanical work instead of creating:
Editing long videos down into short clips
Manually finding the 30–60 second &quot;viral&quot; moment in a 40-minute video
Reformatting horizontal video into vertical 9:16 for Shorts/Reels/TikTok
Writing captions, titles, and hashtags for each platform separately
Publishing the same content across 4–5 different platforms
Tracking what actually performed well
Most creators would rather spend that time creating new content than repackaging old content.

MVP Features
1. Authentication
Users can:
Register
Log in
Reset password
Manage their profile
Build with: Supabase Auth (free) — handles all of the above with a few lines of code, no need to build it from scratch.
2. Video Upload
Users can:
Upload MP4 files
Upload MOV files
Paste a YouTube URL
The system stores files securely.
Build with: Supabase Storage (free tier) for uploads; yt-dlp (open-source) to pull video from a pasted YouTube URL.
3. AI Transcription
The system automatically:
Extracts audio from the video
Generates a transcript
Detects the spoken language
Stores word/segment timestamps
Output: transcript text, timestamp metadata, and speaker segments.
Build with: faster-whisper (open-source, free) run on Google Colab&apos;s free GPU tier or locally on CPU for short clips.
4. Viral Clip Detection
The system analyzes the transcript and identifies:
Hooks
Emotional moments
Educational moments
High-retention segments
Storytelling segments
Output: a ranked clip list with a viral score and start/end timestamps.
Build with: a free LLM (Groq&apos;s Llama 3.1 free tier, or local Ollama) prompted to score transcript segments — no need for a custom-trained model for the MVP.
5. Auto Clip Generation
The system automatically:
Cuts clips at the identified timestamps
Converts to 9:16 vertical format
Centers the speaker in frame
Adds burned-in subtitles
Exports HD video
Output: ready-to-publish short-form video files.
Build with: FFmpeg (free, open-source) for cropping, reframing, and subtitle burn-in. OpenCV (free) can assist with basic face-centering.
6. Caption Generator
Generates platform-specific captions for YouTube, Instagram, TikTok, and LinkedIn.
Build with: free-tier LLM (Groq/Ollama) with a different prompt template per platform.
7. Title Generator
Generates viral titles, SEO titles, educational titles, and curiosity-based titles.
Build with: same free LLM, multiple prompt styles run in parallel.
8. Hashtag Generator
Generates relevant hashtags using topic analysis, platform optimization, and trend matching.
Build with: free LLM for topic extraction; a static, manually curated trending-hashtag list per platform (refresh weekly) to avoid needing a paid trends API.
9. Publishing
Phase 1: YouTube (via the YouTube Data API free quota).
Phase 2: Instagram, TikTok, LinkedIn, and X — added once Phase 1 is stable and free-tier API access is confirmed for each platform.
Many platform APIs require app review for posting permissions — budget time for this, not money.

Using This Project for Content Creation
Because this project is both a product and a process, it doubles as an ongoing content series. A simple framework:
Build-in-public posts: short LinkedIn updates each time a feature ships (&quot;Today I got Whisper transcribing a 40-minute podcast for free using Colab&apos;s GPU&quot;).
Problem-first posts: explain the creator pain point before showing the feature that solves it.
Stack breakdown posts: &quot;How I&apos;m building an AI SaaS for $0/month&quot; — a natural, high-interest post format.
Demo clips: since the product itself generates short-form clips, use CreatorPilot AI to generate the Reels/Shorts about CreatorPilot AI.
Lessons-learned posts: free-tier limits, API rejections, and bugs make better content than a frictionless build — be specific about what broke and how it was fixed.
