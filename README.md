# CreatorPilot AI

A student-built zero-cost AI content operating system for creators.

This repository contains the first scaffold for CreatorPilot AI with a Next.js frontend and FastAPI backend.

## Structure

- `frontend/`: Next.js + Tailwind app shell for creator workflows
- `backend/`: FastAPI service for upload, transcription, and clip generation APIs
